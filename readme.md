# Abax Tracker 🎲

**Abax Tracker** is a lightweight, modern **Progressive Web App (PWA)** designed for tracking scores and gameplay progression in board games.

The app is optimized for seamless offline functionality across mobile devices and desktop browsers.

---

## 🚀 Features

- 📱 **Progressive Web App (PWA)** – Installable on mobile devices and desktops directly from your browser.
- ⚡ **Offline First** – Powered by a Service Worker to ensure full functionality without an active internet connection.
- 🎨 **Modern Interface** – Clean, responsive layout tailored for touchscreens and varying screen sizes.
- 🖼️ **Full Asset Support** – Includes a complete set of PWA icons, including maskable support for modern Android devices.

---

## 🛠️ Tech Stack

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Service Worker API**
- **Web App Manifest**

---

## 📦 Getting Started

### Local Setup
1. Clone or download this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/abax-tracker.git
   ```
2. Open `index.html` in your preferred web browser.

### Deploying with GitHub Pages
1. Navigate to your repository **Settings**.
2. Go to the **Pages** section on the left sidebar.
3. Under **Source**, select the `main` (or `master`) branch and set the folder to `/ (root)`.
4. Click **Save**. Your app will be published at:
   `https://k-d-s-z.github.io/abax-tracker/`

---

## 📱 Mobile Installation

1. Open the app link in your mobile web browser (e.g., Chrome, Safari, Brave).
2. Tap the browser menu and select **"Add to Home Screen"** or **"Install App"**.
